# 🚀 Featured Projects

## 🤖 EMOBOT — Emotion-Aware AI Rover

> AI-powered rover for real-time human–robot interaction.

- Architected a **modular client-server architecture** for real-time speech processing.
- Built **REST-based communication** between AI services and rover control.
- Integrated **UART communication** with Arduino for low-latency command execution.
- Optimized the inference/request pipeline, reducing end-to-end response latency by **66%**.
- Integrated AI inference with **Jetson Xavier + Arduino**.

**Tech:** `Python` `C++` `Llama 3.1` `Librosa` `Praat` `Jetson Xavier` `Arduino`

- Optimized object detection and waypoint scheduling.
- Achieved **85.6% detection accuracy**.
